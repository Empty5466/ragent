# 考试与成绩

## 考试安排

- 期末考试集中在第 17-18 周，考试安排在考前 3 周发布，登录教务系统"考试安排"页查询
- 每门课程的考试时间、教室、座位号以教务系统公布为准，与课表时段无关
- 同一时间段只能安排一门考试，冲突时按"必修优先"原则调整，需在公布后 3 天内向教务处申请变更

## 成绩构成与查询

- 课程总评成绩一般由平时成绩（30%-40%）和期末成绩（60%-70%）构成，具体比例以课程大纲为准
- 成绩于考试结束后 7 个工作日内公布，登录教务系统"成绩查询"查看，支持按学期筛选
- 对成绩有异议的，可在公布后 5 个工作日内提交成绩复查申请，超期不再受理

## 缓考与补考

- 因病或因事无法参加考试的，须在考试前提交缓考申请并附证明材料，擅自缺考按旷考处理，成绩记 0 分
- 必修课不及格可参加下学期初的补考，补考不收费用；补考仍未通过的需随下一届重修
- 重修课程与正常上课班级同考核标准，重修成绩按实际分数记载并标注"重修"

## 常见问题

### 对成绩有异议怎么办？
答：成绩公布后 5 个工作日内在教务系统提交复查申请，教务处会组织任课教师核对，超期不再受理。

### 考试时间冲突了怎么办？
答：考试安排公布后 3 天内向教务处申请变更，按"必修优先"原则协调。

### 挂科了怎么补考？
答：必修课不及格可参加下学期初的补考，免费；补考再不过就要跟下一届重修该课程。

### 缓考需要什么条件？
答：因病（附医院证明）或因事无法参加考试的，考试前提交缓考申请；不经批准擅自缺考按旷考处理记 0 分。

### 成绩什么时候出？
答：考试结束后 7 个工作日内公布，在教务系统"成绩查询"里查看。
